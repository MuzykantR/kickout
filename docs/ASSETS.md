# Kickout — Asset Specification Sheet

Этот документ — **контракт между движком и художником / генератором текстур**.
Каждая запись описывает: размер, число кадров, тему оформления (вузовский
сеттинг — высшая математика, программирование, студенческий быт) и палитру.

Файлы по умолчанию ищутся по путям из манифеста в `Game::loadTextures()`.
Если файла нет — рисуется цветной прямоугольник `ek::kColor*` фиксированного
размера `ek::kSize*` (см. [`include/core/EntityFactory.hpp`](../include/core/EntityFactory.hpp)).
Игра запускается и проходима даже без единого PNG.

Все sprite-sheet'ы — **горизонтальная полоса** одинаковых ячеек.
Формат: `PNG`, прозрачный фон, без `setRepeated`.

## 6. Фон уровня

Поле `background` в JSON уровня указывает путь к фоновой картинке.
Если файла нет — рисуется сплошной цвет неба `(120, 150, 190)`.
Фоны хранятся в `assets/textures/backgrounds/`. Рекомендуемое разрешение
1920×1080 или любое — будет растянуто на окно.
